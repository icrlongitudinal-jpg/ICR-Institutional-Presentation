# GUARÁ Lab — demonstração pública v0.1

**Status:** protótipo de interface navegável; não é o ICR Runtime e não é uma solução governamental homologada.

## Abrir e experimentar
1. Faça o download do arquivo [index.html](./index.html) (no GitHub, abra o arquivo e clique em **Download raw file**).
2. Abra o arquivo no navegador, sem instalar software.
3. Crie um projeto **fictício**, registre fatos, hipóteses, interpretações e decisões.
4. Exporte o projeto demonstrativo em JSON.
5. Use o botão para apagar os dados de laboratório.

Os registros ficam apenas no armazenamento local do navegador (localStorage). Não existe servidor, conta de utilizador, sincronização ou transmissão intencional desses registros para serviços externos pela demonstração. Apagar dados do navegador também pode eliminar os registros.

## Objetivo da demonstração
Ilustrar a proposta de continuidade cognitiva e governança contextual: preservar a sequência inteligível de registros associados a um trabalho. O experimento não comprova continuidade durante falha de sistemas externos, nem interoperabilidade ou soberania digital operacional.

## Limitações e segurança
- **Nunca use dados reais, pessoais, sigilosos ou institucionais.**
- Sem autenticação, perfis, controle de acesso, criptografia em repouso, trilha de auditoria íntegra, backups ou recuperação entre dispositivos.
- Sem integração com Microsoft, Serpro, ENAP, Ministério Público, serviços de IA ou com o núcleo proprietário do ICR.
- Não há relação, contratação, apoio ou aprovação institucional da ENAP.
- A versão demonstrada não equivale ao pacote GUARA Lab com API/SQLite: este é um demonstrador de navegador para facilitar uma primeira avaliação.
- Não é adequado para implantação em redes públicas ou órgãos governamentais.

## Roteiro sugerido de 5 minutos
1. Criar o projeto fictício "Continuidade de Atendimento".
2. Registrar um **fato**: "A equipe recebeu uma solicitação simulada".
3. Registrar uma **hipótese**: "A demora pode depender de uma validação externa".
4. Registrar uma **interpretação**: "O projeto precisa preservar o motivo da espera".
5. Registrar uma **decisão**: "A equipe fará a verificação simulada amanhã".
6. Exportar JSON e verificar a sequência de registros.

## Próximos passos técnicos
Para um piloto institucional real: localizar e auditar o ICR Runtime, integrar a camada de contexto, implementar controle de identidade/permissões, base independente, backups, observabilidade, testes de indisponibilidade e documentação de segurança. A realização depende da aprovação e do escopo acordado com a instituição.
