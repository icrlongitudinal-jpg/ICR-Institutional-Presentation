# GUARÁ | Experiência exploratória de sete dias para Eunice

**Estado:** demonstração pública de conceitos, com dados fictícios; não é uma implantação nem avaliação oficial da ENAP.

## Abrir
Abra o arquivo [index.html](./index.html) localmente no navegador. Para hospedar via GitHub Pages, é preciso configurar a branch/pasta de publicação; este diretório sozinho não comprova que o site está publicado.

## Sete etapas de avaliação
1. Contexto: identificar e classificar um fato.
2. Documentos: redigir uma minuta fictícia.
3. Comunicação: registrar uma mensagem local e hipótese.
4. Agenda: marcar um compromisso fictício.
5. Governança: separar interpretação de decisão e autoria declarada.
6. Transição: gerar resumo local e exportar JSON.
7. Avaliação: verificar recuperação local e documentar limitações.

## O que existe / o que não existe
- **Funciona:** interface estática; inserção de minutas, mensagens, compromissos e referências a arquivos; registro de contexto; armazenamento local no navegador; exportação JSON.
- **Simulado:** e-mail, agenda colaborativa, documentos e arquivos empresariais, gestão institucional, trilha de decisões. Não é suíte Microsoft equivalente.
- **Ausente:** integração real com ICR Runtime; autenticação, permissões, colaboração multiusuário, servidores, sincronização, envio de mensagens, videoconferência, editores Office, recuperação de desastre, auditoria imutável, escalabilidade, testes de segurança.

## Dados e ética
Não inserir dados reais, pessoais ou sensíveis. Dados permanecem no navegador específico; apagar cache pode perdê-los. O botão Restaurar exemplo limpa o ambiente local. O botão Exportar gera um JSON para análise controlada. Não há contador de sete dias, acesso exclusivo a Eunice ou expiração automatizada.

## ICR
ICR é o fundamento conceitual de continuidade cognitiva e governança contextual. O protótipo não contém, não usa e não comprova execução do Runtime proprietário. A integração futura requer API autorizada, validação de autoria, versões, políticas de acesso e testes de segurança. Não publicar segredos ou núcleo proprietário.

## Uso institucional futuro
A hipótese de uma plataforma brasileira alternativa a serviços Microsoft exige integrar componentes reais de documentos/arquivos, comunicação, identidade e reuniões, governança e infraestrutura; verificar licenças, acessibilidade, LGPD, migração, segurança, soberania e desempenho. Este protótipo não declara equivalência.

Proposta independente. Sem vínculo, patrocínio, homologação ou endosso da ENAP.
